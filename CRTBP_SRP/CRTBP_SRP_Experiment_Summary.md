## 1. 轨道案例

- **来源**：`CRTBP_SRP/crtbp_initial_conditions.json`
- **总计**：128 条周期轨道 × 24 个轨道相位 = **3072 个初始条件**
- 坐标系：地月旋转（会合）系，无量纲；`LU = 384400 km`，`TU = 375237.080249162 s`，`mu = 0.0121536140918916`。
- 每条轨道带 24 个相位 `phase_index = 0..23`（`phase_fraction` 0 → 约 0.958，沿各自已验证的 CRTBP 周期轨道积分得到）。

## 2. 实验设计 Q1–Q4（三层 L1/L2/L3）

> **研究主线**：一维 SRP 强度 → 三维强度–姿态 → 四维强度–反射组成–姿态。
> 本研究是**极端参数域下的动力学敏感性分析**，不是基于真实先验概率的轨道预测不确定度量化。

### 2.0 物理约定（摘要）

- **Cannonball**：`a = -P_eff · β · ŝ`（1 个参数 β）。
- **Flat-plate**：参数 `(β, χ, u, v)`；固定正入射等效系数 `C_eq = 1.5`，
  `ρ_s = 0.5χ`，`ρ_d = 0.75(1-χ)`，基准 `χ₀ = 0.6`。
- **姿态坐标 u,v**：对日局部横向平面内的斜率坐标，
  `n̂ = (ŝ + u·ê₁ + v·ê₂)/√(1+u²+v²)`，`μ = cos_incidence = 1/√(1+u²+v²)`，
  `θ = arctan√(u²+v²)`；矩形域 `u,v ∈ [-q,q]`，`q = tan(θ_max)/√2`。
- **β 单位**：m²/kg（完全对日时的等效 Cannonball 面积反射系数质量比）。

### 2.1 Q1 — 强度敏感性（Layer 1，1D β，Cannonball）

量化不同轨道族/相位对 SRP 强度的响应，建立 1D DA/ADS 基准。

| config | β 区间 (m²/kg) | 意图 |
|---|---|---|
| `Q1_L1_small` | [0, 0.02] | 弱扰动/局部响应基准 |
| `Q1_L1_main` | [0, 0.10] | 主实验 |
| `Q1_L1_ext` | [0, 0.20] | 极端扩展 |

### 2.2 Q2 — 强度 vs 姿态（Layer 2，3D β,u,v，Flat-plate，χ=0.6 固定）

固定反射组成，独立改变等效强度 β 与横向倾斜 u,v，比较幅值扰动与姿态扰动的作用，以及 DA 混合项与 ADS 分裂方向。

| config | β 区间 | θ_max | 类别 |
|---|---|---|---|
| `Q2_L2_t5` | [0.08, 0.12] | 5° | 局部敏感性 |
| `Q2_L2_t10` | [0.08, 0.12] | 10° | 局部敏感性 |
| `Q2_L2_t20` | [0.08, 0.12] | 20° | 局部敏感性 |
| `Q2_L2_ext_main` | [0, 0.10] | 10° | 扩展联合域 |
| `Q2_L2_ext_ext` | [0, 0.20] | 10° | 扩展联合域 |
| `Q2_L2_t30` | [0, 0.20] | 30° | 高倾角扩展（n_split_max=16） |
| `Q2_L2_t45` | [0, 0.20] | 45° | 高倾角扩展（n_split_max=16） |
| `Q2_L2_t60` | [0, 0.20] | 60° | 高倾角扩展（n_split_max=16） |
| `Q2_L2_t85` | [0, 0.20] | 85° | 高倾角扩展（n_split_max=16） |

> 高倾角（30/45/60/85°）由 `tools/run_crtbp_srp_study_batch_highangle.py` 单独驱动；85° 盒子角点半径 `tan85° ≈ 11.4`，远超 DA 映射 `μ=1/√(1+u²+v²)` 的单位收敛半径，需大量分裂，须先 smoke-test。

### 2.3 Q3 — 分裂方向（分析维度，非独立 config）

回答“3D/4D 参数域中 ADS 首次分裂沿哪个参数轴（或组合方向）发生，且随轨道族/相位/太阳相位/时间如何变化”。

- **数据来源**：Q2/Q4 每个案例的 `split_events`（逐次分裂）与 `split_count_dir`（四轴累计）。
- **物理轴编码**：`1=beta, 2=chi, 3=u, 4=v`（`SRP_PARAMETER_NAMES`）。
- **口径**：分别报告首次分裂、全弧累计、按时间窗统计，避免只给最终占比。
- 分析脚本：`tools/analyze_srp_study_progress.py`（分裂次数/方向热力图与汇总）。

### 2.4 Q4 — 反射–姿态耦合（Layer 3，4D β,χ,u,v，Flat-plate）

在 Layer 2 基础上加入 χ，保持所有 χ 的 `C_eq = 1.5` 不变，识别反射组成单独变化（对日时应为零）及 χ–姿态混合非线性。

| config | β 区间 | χ 区间 | θ_max |
|---|---|---|---|
| `Q4_L3_chi01` | [0.08, 0.12] | [0, 1] | 10° |
| `Q4_L3_chi_narrow` | [0.08, 0.12] | [0.4, 0.8] | 10° |
| `Q4_L3_ext` | [0, 0.10] | [0, 1] | 10° |

## 4. 关键运行参数

| 参数 | 值 | 说明 |
|---|---|---|
| `mu` | 0.0121536140918916 | 地月质量比 |
| `LU_km` | 384400 | 长度单位 |
| `TU_s` | 375237.080249162 | 时间单位 |
| `da_order` | 8（默认） | DA 阶数 |
| `err_toll` | 1e-8（默认） | 截断误差分裂阈值（ND） |
| `n_split_max` | 12（主）/ 16（高倾角） | 最大分裂深度 |
| `N_SEGMENTS` | 48 | ADS 时间 checkpoint 数 |
| `N_SAMPLES` | 10000 | 端点统计固定样本数 |
| `SEED` | 20261102 | 固定随机种子（均匀采样） |
| `REL_TOL / ABS_TOL` | 1e-10 / 1e-12 | 积分容差 |
| `BETA_EPS` | 1e-4 | β=0 单边差分步长 |

### 4.1 每个案例的输出（JSON）

- 端点均值 `mean_state`(6)、端点协方差 `cov_state`(6×6 行主序)。
- `n_patches`、`n_splits_total`、`split_count_dir`[beta,chi,u,v]、`n_max_active`、`n_diverged`、`first_split_time`、`first_divergence_time`、`wall_time_s`。
- `split_events`（逐次分裂：时间 `t`/`td`、轴 `ax`、深度 `d`、活跃域 `na`、中心 `c`、半宽 `w`、判据 `crit`）。
- 当 `beta_lower == 0` 时附 `beta_sensitivity`（β=0 处 d(x)/dβ 单边差分）。
- 仅保存**端点**统计，不保存中间时刻的均值/协方差时间序列。
