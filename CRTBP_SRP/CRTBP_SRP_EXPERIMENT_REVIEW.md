T_seconds = period_nd * TU_s
n_periods = 2 if 2*T_seconds >= 15*86400 else 3

duration_seconds = duration_nd * TU_s

## 3. T1 的绝对 beta、零参考与导数

对 beta_max=B：

```text
beta = B/2 + (B/2)*z, z in [-1,1]
T1a: center=0.05, halfwidth=0.05 m²/kg
T1b: center=0.10, halfwidth=0.10 m²/kg
physical_reference_beta = 0
```

现有接口为 `beta=Cr0*(A/m)0*(1+eta_r)`。可通过正的名义乘积 B/2 和 `eta_r=z` 实现，或后续新增显式绝对 beta 接口。不能把名义乘积设为零再乘 `(1+eta_r)`，否则全域光压及其导数都消失。

参考轨道 x_ref(t)=x(t;0) 与 DA 中心轨道 x(t;B/2) 必须分开命名。
若根域映射 x(z)=sum c_k z^k，那么目标导数为：

```text
S_beta0(t) = (2/B) * [d x(z)/d z] evaluated at z=-1
```

不能拿中点的一阶系数直接当 beta=0 导数。ADS 分裂后应使用包含 beta=0 的叶域映射，并按该叶域的物理半宽换算导数。

建议另行沿零光压参考轨道积分 6 维参数变分方程作为该输出的主值或独立校验。若 `x'=f0(x)+beta*g(t,x)`，则：

```text
x_ref' = f0(x_ref)
S' = Df0(x_ref)*S + g(t,x_ref), S(0)=0
```

也可使用 beta=0 中心的局部 DA。边界差分验证应采用单边差分及步长收敛，不把负 beta 当物理采样域。这条导数轨道与 beta_max 无关，T1a/T1b 在相同初值、太阳几何和积分设置下可复用。

## 4. T2 尚需明确的物理定义

附件的平板公式与现有 panel 力公式一致。rho_s=rho_d=0.3 时：

```text
C_eq = 1 + rho_s + 2*rho_d/3 = 1.5
beta_face_on = C_eq*A/m
A=80,  m=1200 -> beta_face_on=0.1 m²/kg
A=180, m=1200 -> beta_face_on=0.225 m²/kg
A=160, m=1200 -> beta_face_on=0.2 m²/kg
```

因此 80 m² 与 T1a 上端点精确对齐，180 m² 比 T1b 上端点高 12.5%。选择必须明确：

1. 保留用户的 180 m²，承认扩展实验正入射为 0.225，并增加 beta=0.225 的 CB 对照；
2. 若要求正入射上限严格为 0.2，则改用 160 m²（需要用户改变面积要求）；
3. 保留 180 m² 但引入额外幅值因子，上限为 8/9，明确这是等效缩放。

如果 A、m、rho 均固定，则 beta 固定。只有 u,v 不确定时是二维姿态实验；附件三维 `(beta,u,v)` 还需定义有效面积或等效幅值缩放。零 SRP 仍可作为人为关闭光压的参考，但不是这块固定受光平板的材料参数下界。

还需确定：u/v 域宽、联合分布、板法向是否遵循随太阳转动的对日规律，以及横向基在会合系中的构造。完整日距模型中太阳视线依赖状态，若法向跟随实际视线，则相应基和法向也必须保留 DA 状态依赖，不能未经声明使用参考轨道上的固定实数视线。

## 5. 逐小时统计的定义

建议输出 t=0、1h、2h、…、floor(tf/1h)h，并额外输出精确 tf（无重复）。太阳相位使用连续时间，不在每小时或分裂时重置。

每个时刻保留：

- time_seconds/time_nd、参考状态、六维 beta=0 导数及单位；
- 分布均值、6×6 协方差（含位置速度互协方差）、样本数、有效样本数；
- HZ statistic、p_value、检验维数、秩、条件数/秩阈值、检验状态及采用的样本集合；
- 当前子域数、累计分裂数、数值/域覆盖状态。

必须先定义参数分布。区间本身不能定义协方差或 HZ 的采样总体。一个可选的实验测度是 `beta~Uniform(0,B)`，但这不是实际先验，也不是用户已确认的选项。T2 在 uv 矩形均匀与在球面圆锥均匀不是同一分布。

协方差应围绕分布均值计算。相对零光压参考的二阶矩是：

```text
E[(x-x_ref)(x-x_ref)^T] = Cov(x) + (E[x]-x_ref)*(E[x]-x_ref)^T
```

不能把这两个量混称为协方差。对于 ADS 子域，要按原参数分布的概率质量合并，不能对子域等权；最简单的可复现方式是固定一组全局参数样本，逐小时在 ADS 映射上求值。保留样本参数/编号，避免每小时重新抽样导致额外统计波动。HZ 的标准 p 值基于 iid 样本；规则网格、求积点、确定性低差异点不能无说明地套用同一 p 值标定。

### HZ 的特殊问题

HZ 检验非退化多元正态性，不是直接检验动力学非线性。原始文献和公式要求需在检验解释中保留：

- [Henze & Zirkler (1990)](https://www.tandfonline.com/doi/abs/10.1080/03610929008830400)
- [Stata HZ 公式与计算复杂度](https://www.stata.com/manuals/mvmvtestnormality.pdf)

本任务初值固定，T1 仅一个随机参数。平滑传播的六维状态支撑在一条参数曲线上，不是非退化六维正态总体；线性极限的协方差秩至多为 1。非线性曲线的样本协方差可以满秩，不能把“一个输入参数”误说成“协方差永远 rank=1”。平面轨道在共面炮弹球几何下还保留 z=vz=0，完整六维协方差会有严格退化。

若 beta 均匀，线性传播的参数响应也并非高斯；因此 HZ 拒绝不能单独当作发生动力学非线性的证据。可以保留用户要求的 HZ，但应同时报告非线性残差、秩和检验状态。

现有 `tools/srp_unified_math.py:82` 已按块计算 HZ，并对奇异协方差返回 `status=singular_covariance, p_value=None`；可复用其语义。不要添加人为噪声把奇异协方差强行变为可逆。若改用子空间/三维检验，应明确检验对象改变，结果不可与完整六维 p 值直接混用。

## 6. ADS 事件和末端分布

首次分裂须由推进中的判据触发，记录判定步端点或定位区间；逐小时输出节拍不能冒充首次分裂的时间分辨率。
现有 `pod_uq_crtbp_ads_module` 在积分到 t_end 后做参数域分裂，尚不能直接满足沿时间首次分裂日志。
该模块还存在“达到最大分裂深度即接受”的分支；新实验须把阈值未满足但资源耗尽的结果标记为未通过精度认证，而非正常完成。

每次事件至少包括 case/domain/parent/children ID、时间、参数名、分裂前后物理及标准化域界、判据/阈值/方向分数、阶数、深度、活跃域数。
无分裂工况的 first_split 应为 null 并附完成标志，不能写成 tf、0 或与失败工况混合。

末端建议同时保留样本的输入参数、六维状态、有效性/终止原因、权重或可恢复权重的信息；另存末端 ADS 叶域和 DA 映射，便于重新求值。失败/碰撞/未覆盖样本不得静默删除后仍声称统计了完整原分布。

### 7.2 同时运行的 RAM

跑完全部工况的存储量不等于同时所需 RAM。按 W 个独立进程并行：

```text
RAM_peak ~= M_scheduler + W * (M_runtime + M_ADS_peak + M_sample_buffers + M_HZ_buffers)
```

N=10000 的一个六维样本数组只有 0.458 MiB。现有 HZ 使用 B=256 的分块距离矩阵：一个 B×N float64 缓冲区为 19.531 MiB；N_HZ=2000 时为 3.906 MiB。表达式临时数组会使峰值同时包含多个这样的缓冲区。
若错误地创建完整 N×N 矩阵，N=10000 时单矩阵为 0.745 GiB，N=100000 时为 74.506 GiB。现有分块实现可以避免这一平方级 RAM，但计算量仍为 O(N_HZ²)。

ADS 内存受最大活跃子域数 P、阶数 p、参数维数 d 控制。每个状态多项式最多有 `K=binomial(p+d,d)` 个系数，仅六维状态的 double 系数载荷为 `48*P*K` 字节：

| 情景：p=6，P=10000 | K | 六维系数数值负载 |
|---|---:|---:|
| T1 d=1 | 7 | 3.204 MiB |
| 附件式 T2 d=3 | 84 | 38.452 MiB |
| 附件 T3 d=4（不计当前任务） | 210 | 96.130 MiB |

这不是 DACE 实际对象容量：还需系数索引、分配容量、参数映射、历史、队列/拷贝、编译映射、积分中间级和运行库。ADS 子域数未定，无法据此给出有保证的每进程上限或声称某台内存规格一定足够。

应在 ADS 文档确定 p/P/阈值后，用相同任务分别做短、中、全弧代表工况，记录峰值 RSS、活跃/累计域数和运行时间，据此限制 W。必须有 max_patches / max_depth / 内存预算耗尽的明确状态。

HZ 也可能主导计算量：四组共有 8,514,720 个时刻记录，若全部都用 N_HZ=2000 做完整成对和，约涉及 3.406e13 个矩阵元素的计算量（退化时刻可提前返回）。可以固定一个可复现的 iid 子样本用于逐小时 HZ，协方差及末端分布用更大 N；具体 N 和子样本策略需要确定，不能随意改变样本量后横向比较 p 值。

## 8. 建议的确定顺序

1. 固定当前必做矩阵：T1a/T1b、T2a/T2b，轨道相位和太阳相位数；T3及局部/小范围扫描单列可选。
2. 确定 T2 的 180 m²/0.2 对齐口径，以及固定 beta 还是等效幅值缩放。
3. 确定参数分布、独立性、N_eval/N_HZ/N_final、检验维数和退化状态处理。
4. 固定单工况结构：初值、时长、模型，加 mu/DU/TU、太阳配置、参数域、统计配置和后续 ADS 配置；实验级默认值展开后写入每个工况元数据。
5. 接入绝对 beta/参数映射、零参考及导数；验证 CB–FP 在同一 beta 且对日时整段轨迹一致。
6. 按后续 ADS 文档接入时间推进、分裂日志及资源上限，完成端点/角点/直接积分误差验证。
7. 完成代表工况的峰值 RSS 和耗时测量，确定并行数后再启动全部工况。

当前阻止唯一确定实验规模与 RAM 上限的内容：T2 参数定义、参数分布及采样数、太阳相位数、ADS 阶数/判据/最大子域数。其余明确要求已经可以直接写入最终规格。
