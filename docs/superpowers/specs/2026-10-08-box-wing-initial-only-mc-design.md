# Box-Wing 对地/对月初始误差 ADS–MC 传播设计

日期：2026-10-08
状态：用户已确认设计口径，等待书面规格复核

## 1. 目标

在现有炮弹球 SRP 不确定性实验之外，增加两组只含 OPM 初始状态误差的传播：

1. `box_wing` 对地定向，固定 `eta=0`；
2. `box_wing` 对月定向，固定 `eta=0`。

两组使用与当前炮弹球实验完全相同的 OPM、固定 MC 样本编号和前六维样本坐标，传播 15 天并每小时记录结果。输出用于检验炮弹球模型加 SRP 参数不确定性形成的状态域能否覆盖对地和对月 box-wing 模型。

本任务不修改或重启当前正在执行的炮弹球批量任务。

## 2. 物理模型和配置

新增两份独立配置，不修改 `config/config.txt`：

- `config/config_box_wing_earth.txt`
- `config/config_box_wing_moon.txt`

两份配置继承当前正式实验的全部动力学、积分器、尺度、星历、活动天体和引力设置。共同参数采用 `SRP/260915_srp_acceleration_history/README.md` 中已运行验证的数值：

| 参数 | 值 |
|---|---:|
| 质量 | 1200 kg |
| 箱体尺寸 | 2 × 3 × 4 m |
| 箱体吸收/镜面/漫反射 | 0.30 / 0.40 / 0.30 |
| 太阳翼总面积 | 24 m² |
| 正面吸收/镜面/漫反射 | 0.85 / 0.08 / 0.07 |
| 背面吸收/镜面/漫反射 | 0.60 / 0.20 / 0.20 |
| 太阳翼控制 | `single_axis` |
| 铰链轴/参考法向 | `[0,1,0]` / `[1,0,0]` |
| 定姿主轴/辅助轴 | `+Z` / `+Y` |
| 滚转参考 | `orbit_normal` |
| 1 AU 太阳光压 | `1367 / 299792458 N/m²` |

两份配置分别使用 `srp_attitude_mode=earth` 和 `srp_attitude_mode=moon`。姿态偏差、太阳翼角度误差和 SRP 全局倍率误差均为零。

## 3. 不确定域与样本配对

每条轨道读取 OPM 的完整 6×6 协方差并建立白化 ±3σ ADS 域。只有六个初始状态变量参与不确定性传播，ADS 活跃维数为 6，物理 SRP 倍率始终为 1。

复用 `20261005SRP/samples/mc_standard_normal_50000.csv`：

- 使用相同的 `sample_id=1..50000`；
- 只使用 `z1..z6` 和 `u1..u6`；
- 忽略 `z7`、`u7` 和 `eta_treatment`；
- 每条轨道通过自己的 OPM 协方差映射到物理初始状态。

box-wing 对地、box-wing 对月及现有炮弹球两组可按 `(orbit,hour,sample_id)` 严格对齐。

## 4. 传播接口

新增独立程序 `run_srp_ads_mc_initial_only`，必需参数为：

```text
-opm INPUT.opm.json
-o OUTPUT_PREFIX
--mc-samples SAMPLE.csv
-cfg CONFIG.txt
```

默认参数与当前正式实验一致：50,000 个 MC 点、2,048 个逐小时可视化点、15 天、1 小时间隔、DA 4 阶、最大分裂深度 8、位置验证阈值 0.1 km、速度验证阈值 `1e-6 km/s`。

程序只接受 `box_wing` 且姿态为 `earth|moon` 的配置。每小时从上一小时的 ADS 补丁继续传播。

## 5. 参考中心

每组保存本组零初始误差名义中心、样本相对本组中心的误差以及已落盘样本的绝对状态。

后续覆盖分析必须使用炮弹球 `eta=0` 名义中心作为共同参考：

```text
e_earth = x_earth - x_cannonball_nominal
e_moon  = x_moon  - x_cannonball_nominal
```

这样可保留姿态模型造成的名义轨道偏移。本任务生成足以重建共同参考误差的数据；覆盖率和越界距离由后续比较工具计算。

## 6. 求值与保存

在 0..360 h 的 361 个时刻，对全部 50,000 点进行 ADS 求值并计算逐小时统计。

沿用现有存储口径：

1. 每小时保存固定的前 2,048 个 `sample_id`；
2. 在 0、24、72、168、240、360 h 保存全部 50,000 点；
3. 第一次 ADS 分裂、第一次达到最大深度、第一次验证失败的前一小时和发生小时保存全部 50,000 点；
4. 重复关键时刻只保存一次；
5. ADS 补丁快照只在起点、终点和事件相关关键时刻保存；
6. 首次验证失败后继续传播和保存，并设置 `ads_accuracy_valid=false`。

## 7. 输出

每条轨道、每种姿态输出：

- `*_mc_hourly.csv`：逐小时统计、名义中心、补丁和验证诊断；
- `*_mc_points.csv` 及批处理打包的 HDF5：每小时 2,048 点和关键时刻 50,000 点，含绝对状态与本组误差；
- `*_split_events.csv`：全部 ADS 分裂事件和完整判据；
- `*_mc_report.json`：输入、哈希、参数、首次事件和完整性摘要；
- `patch_snapshots/`：关键时刻补丁范围、分裂历史和稀疏 DA 系数。

所有文件记录 schema、模型、姿态、OPM/config/样本哈希、历元、单位、活跃维数和 ADS 有效性。

正式结果目录为：

```text
20261005SRP/results_box_wing_initial_only/
├── earth/<OPM相对结构>/
└── moon/<OPM相对结构>/
```

单轨在临时目录运行，全部文件审计成功后原子发布；失败结果留在 staging 并写入审计表。

## 8. 失败诊断

保留现有 ADS 诊断：补丁数、各方向分裂数、最大深度、队列峰值、第一次分裂完整判据以及独立实数验证误差。box-wing 力模型返回的姿态或太阳翼后备状态必须进入日志。单轨失败不得终止整批任务。

## 9. 验证

1. 两份配置可由 `pod_engine_init` 读取并通过 `validate_config`，除姿态模式外完全相同。
2. 配置数值与 `260915` 实验一致，SRP 比例误差、姿态误差和翼角误差为零。
3. 6D 域只使用 `u1..u6`，样本编号与炮弹球实验一致。
4. 第七维变化不影响 box-wing 初始状态或传播结果。
5. 对地和对月短时 Real/DA 常数项一致。
6. 1 h 真实单轨测试满足现有 ADS 验证阈值，并检查 2,048/50,000 点保存规则。
7. 一条完整 15 天运行具有 361 个唯一小时、每小时 50,000 点统计、稳定的 2,048 个逐时点号以及可解析的事件、报告和快照。
8. 短时和完整单轨门禁通过后才建立全轨道批处理。

## 10. 完成标准

1. 两份配置完整且不影响当前炮弹球任务。
2. 两组均为 6D 初始误差传播，SRP 参数误差严格为零。
3. 固定样本与炮弹球实验按 `sample_id,u1..u6` 严格一致。
4. 每小时和关键时刻保存数量符合既定设计。
5. 名义中心、相对误差和绝对状态足以重建共同参考覆盖关系。
6. 分裂、最大深度、验证失败和 box-wing 几何后备均有诊断。
7. 一条真实轨道通过完整 15 天端到端验证后，才允许启动正式批量任务。
