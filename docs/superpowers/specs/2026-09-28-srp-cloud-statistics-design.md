# SRP 配对误差云统计与高斯样本可行性审计设计

日期：2026-09-28

## 1. 目标与范围

对已完成的 15 条非 L2NRHO 轨道，比较两组传播结果：

- 处理组：保留标称炮弹球 SRP，SRP 相对倍率不确定性 `sigma_eta = 0.3`。
- 控制组：保留相同标称炮弹球 SRP，固定 `eta = 0`。

方案一直接使用每小时相同 `point_id` 对应的 512 个固定设计点，不重新传播。分析只使用处理组与控制组均通过 ADS 验证且未出现 `precision_unconfirmed` 的连续前缀；首次无效时刻及其后时刻保留在原始审计 CSV 中，但不进入图、峰值、总体分位数和积分。

本次不包含 `L2NRHO-1/2`，不计算散度。

## 2. 单位

- 位置及位置点云尺度：km。
- 速度及速度点云尺度：km/s。
- 偏度、超额峰度、相对最大误差：无量纲。
- 时间：h。

现有以 m 和 mm/s 输出的派生字段与图将改为 km 和 km/s，不在新版汇总中混用旧单位。

## 3. 每小时误差云指标

令第 `i` 个固定设计点相对于原点传播结果的六维误差为：

`e_i = [dx, dy, dz, dvx, dvy, dvz]`。

输入 `shape.csv` 中的六维误差已经相对于同一组标称原点轨道表示，因此 512 点均值与原点传播结果的差就是六维误差点云的质心。

### 3.1 均值与原点传播结果之差

分别保存六个均值分量，并绘制：

- 位置均值偏移：`norm(mean(dx,dy,dz))`，单位 km。
- 速度均值偏移：`norm(mean(dvx,dvy,dvz))`，单位 km/s。

处理组和控制组使用同一坐标轴叠加显示。

### 3.2 协方差最长轴

位置和速度不能直接组成一个未经尺度化的六维协方差特征值问题，因此分别计算：

- 位置协方差最长 RMS 轴：`sqrt(max(eigenvalue(Cov(dx,dy,dz))))`，单位 km。
- 速度协方差最长 RMS 轴：`sqrt(max(eigenvalue(Cov(dvx,dvy,dvz))))`，单位 km/s。

协方差按固定设计点总体矩计算，分母为 `N=512`，与现有 PCA RMS 轴定义一致。

### 3.3 六维最大偏度

对六个分量分别计算总体标准化三阶矩：

`skew_j = mean((x_j - mean(x_j))^3) / mean((x_j - mean(x_j))^2)^(3/2)`。

每组每小时保存：

- 六个带符号偏度；
- 最大绝对偏度；
- 达到最大绝对值的分量名；
- 该分量的带符号偏度。

若某分量方差接近零，该分量记为不可计算，不参与最大值选择。

### 3.4 六维最大超额峰度

对六个分量分别计算总体超额峰度：

`excess_kurtosis_j = mean((x_j - mean(x_j))^4) / mean((x_j - mean(x_j))^2)^2 - 3`。

保存内容与偏度相同：六分量值、最大绝对值、对应分量名和带符号值。高斯参考值为 0。

固定 512 点不是独立概率样本，因此偏度和峰度只解释为误差域几何形状的非高斯指标，不作为正式的概率正态性检验。

### 3.5 最大误差相对整个误差云大小

位置指标定义为：

`relative_max_position = max_i(norm(r_i - r_origin)) / position_longest_rms_axis`。

其中分子使用相对于原点传播结果的最大绝对位置误差，分母使用位置协方差最长 RMS 轴。另保存分子和分母的 km 值，防止仅看比值造成误读。

速度使用相同定义，并以速度最长 RMS 轴归一化。若分母接近零，比值记为空值。

## 4. 首次分裂比较

处理组旧格式没有完整 `split_events.csv`，因此两组统一按累计计数比较：

- 从逐时 `history.csv` 的 `split_dim1...split_dimN` 找到累计分裂数首次大于零的保存时刻 `h`。
- 首次分裂区间报告为 `[h-1, h] h`；若 `h=0`，报告起点。
- 处理组统计方向 1–7；控制组统计方向 1–6，并验证第 7 方向累计数恒为零。
- 保存处理组时刻、控制组时刻、二者差值、首次出现非零的方向集合。
- 旧处理组无法恢复同一小时内多个分裂事件的严格先后顺序、截断误差和方向评分，报告中明确标注这一限制。

绘制一张 15 轨道分组点图或条形图，比较两组首次分裂保存时刻；未发生分裂的轨道单独标记，不使用数值 0 代替。

## 5. 输出文件与图片

### 5.1 CSV

- `cloud_statistics/<orbit>_cloud_statistics.csv`：每条轨道逐时处理组/控制组的均值偏移、最长轴、六维偏度、六维超额峰度、相对最大误差和有效性。
- `cloud_orbit_summary.csv`：每条轨道有效终点、峰值、峰值时刻、时间平均值，以及首次无效时刻。
- `first_split_comparison.csv`：两组首次分裂区间、时刻差和可恢复的方向信息。
- `paired_population_history.csv`：继续只使用有效轨道，位置单位改为 km、速度单位改为 km/s，并保留每小时有效轨道数。

原始 `paired_history` 保留以便审计；日常分析优先使用 `paired_history_valid` 和 `cloud_statistics`。

### 5.2 图片

每条轨道生成：

1. `<orbit>_cloud_moments.png`：六面板，显示有/无 SRP 参数不确定性时的位置均值偏移、速度均值偏移、位置最长轴、速度最长轴、六维最大绝对偏度、六维最大绝对超额峰度。
2. `<orbit>_relative_max_error.png`：两面板，显示位置和速度最大误差相对最长 RMS 轴的比值，并在图注中说明无量纲定义。

批次生成：

3. `first_split_comparison.png`：15 条轨道两组首次分裂时刻及差异。
4. 保留位置/速度 SRP 点对点增量图，但单位分别改为 km 和 km/s；无效区段继续截断。

## 6. 方案二可行性审计

方案一完成后，不启动新的传播，只审计当前保存文件能否直接计算“概率高斯样本”每小时结果：

1. 检查现有 512 点的生成规则、`u1...u7`、概率权重和固定 `point_id` 是否足以代表目标高斯分布。
2. 检查每小时是否保存了可对任意初始样本求值的完整 ADS 补丁、域映射和稀疏 DA 系数。
3. 检查快照覆盖的小时集合，以及失准后快照是否仍可用。
4. 判断三种结论之一：
   - 可以直接离线计算每小时高斯样本；
   - 只能在保存完整补丁快照的关键小时计算；
   - 必须重新传播或增加逐时 ADS 快照。
5. 给出若可行时所需样本生成、补丁归属、求值、权重、收敛检查和文件规模方案；不给出未经数据验证的肯定结论。

## 7. 验证

- 合成对称点云：偏度为 0，高斯型合成样本超额峰度接近 0。
- 已知非对称和重尾点云：最大绝对偏度、峰度及对应分量识别正确。
- 单位检查：位置派生量为 km，速度派生量为 km/s，不再出现 m 或 mm/s 字段。
- 有效性检查：`L1PL-2` 从 259 h 起不进入统计；DRO 三条轨道保留 0–360 h。
- 首次分裂检查：累计计数首次非零时刻与源 `history.csv` 一致，控制组方向 7 为零。
- 完整运行：15 条轨道均生成 CSV 和图片，所有汇总可解析，图中无已排除的极端值。

## 8. 已知限制

- 处理组旧格式缺少逐事件分裂判据和严格构建来源信息。
- 512 点是固定设计点，不能用其偏度和峰度直接完成概率高斯性检验。
- 首次分裂只有一小时保存分辨率。
- ADS 首次失准后的点云不进入物理结论。
